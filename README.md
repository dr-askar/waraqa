# ورقة — تطبيق ويب قابل للتثبيت

تطبيق عربي RTL يعمل من Chrome على Android، دون APK. التنفيذ HTML/CSS وJavaScript modules بدون حزم خارجية للميزات المحلية. تخزين الصور والمستندات في IndexedDB والمعالجة Canvas داخل الجهاز.

## الميزات

- كاميرا مباشرة مع بديل كاميرا الهاتف، واستيراد صور متعددة.
- إنشاء مستندات، تعديل الاسم والمجلد، بحث وترتيب، مفضلة وسلة قابلة للاستعادة.
- ترتيب الصفحات، استخراج المحدد لمستند جديد، وجمع عدة مستندات.
- إنشاء صفحة واحدة فعلية من صورتين: أفقي/عمودي، A4/Letter، هوامش، تبديل ترتيب ومعاينة؛ الاحتفاظ بالأصل.
- تقسيم محتوى الصفحة إلى 2–4 صور: اتجاه وخطوط فصل يدوية وترتيب؛ الاحتفاظ بالأصل.
- قص بأربع زوايا وتصحيح منظور، تدوير، رمادي وأبيض وأسود، إضاءة وتباين، استعادة الصورة الأصلية.
- توقيع بالإصبع، رسم وتمييز، نص/تاريخ، طمس مُدمَج في الصورة المصدَّرة. الأصل والنسخ الاحتياطية تحتوي معلومات قبل الطمس، فلا تُشارك كنسخة منقّحة.
- PDF متعدد الصفحات دون علامة مائية، جودة قابلة للاختيار، تنزيل JPG/PNG، مشاركة ملفات مدعومة على Android، وطباعة عبر المتصفح.
- نسخ احتياطي واستعادة `.waraqa`، مع الاحتفاظ بنسخة منفصلة عند تعارض الاستعادة.
- تثبيت PWA ووضع داكن، وتخزين واجهة التطبيق للعمل بدون إنترنت بعد أول تحميل ناجح.
- Google Drive اختياري: OAuth من Google Identity Services، نطاق drive.appdata، ومزامنة يدوية بنسخ غير قابلة للاستبدال لتجنّب الكتابة فوق نسخة جهاز آخر. نسخة منفصلة لكل فرع متعارض.

## تشغيل محلي

```sh
python3 -m http.server 4173 --directory dist
```

افتح `http://localhost:4173`. الكاميرا وPWA تحتاج localhost أو HTTPS. الوصول من هاتف إلى IP كمبيوتر عبر HTTP لا يحقق شرط secure context؛ استخدم استضافة HTTPS.

## Google Drive

أنشئ OAuth Client من نوع Web في Google Cloud، فعّل Drive API، واضبط consent screen وأضف مستخدمي الاختبار. أضف الأصل الكامل للموقع في Authorized JavaScript origins. الصق Client ID في الإعدادات، ثم «تجهيز تسجيل Google» وبعدها «ربط الحساب» ثم «مزامنة الآن». لا يحتاج التطبيق Client Secret ولا يخزن access token على القرص؛ تسجيل الدخول لكل جلسة عند الحاجة.

الملفات مخفية في appDataFolder. المزامنة لا تستخدم Drive المتصل بChatGPT. لا تُرفع ملفات تلقائياً، ولا تُرسل الصور إلى خادم OCR. النسخ السحابية القديمة تبقى في حسابك وتستهلك مساحة. فصل الجلسة لا يحذفها ولا يلغي OAuth consent؛ إلغاء الإذن الدائم من حساب Google.

جاهز للنشر على GitHub Pages عبر ملف `.github/workflows/pages.yml`. الموقع المنشور متاح لمن يملك الرابط، لكن صور المستخدم لا توضع في المستودع أو الاستضافة؛ تبقى داخل متصفحه إلا عند المزامنة الاختيارية إلى حسابه في Drive. يلزم اختبار تثبيت PWA والعمل بدون إنترنت على Android فعلي.

## حدود واضحة

- لا يوجد كشف تلقائي لحدود الورقة أو OCR أو PDF قابل للبحث أو تشفير PDF أو قفل ببصمة.
- التوقيع مرئي، غير موثق رقمياً. إضافة النص بموقع افتراضي أسفل الصفحة.
- الصور تُخفض إلى 2400px للضلع الأطول للحفاظ على الذاكرة. حد المستند 80 صفحة، والصورة المدخلة 30MB، وملف الاستعادة 80MB، والمستند المتزامن 50MB.
- Google Drive لم يُختبر بحساب حقيقي لغياب OAuth Client من المستخدم. انتهاء الجلسة والأخطاء ظاهرة، ولا يُعرض نجاح وهمي.
- المزامنة أثناء فتح التطبيق فقط. لا يوجد رفع قابل للاستئناف أو حذف دائم للنسخ السحابية؛ إعدادات الحذف المحلية لا تمسح نسخة Drive.
- المتصفح قد يحذف IndexedDB عند ضغط المساحة أو مسح بيانات الموقع. اطلب التخزين الدائم ونزّل نسخة احتياطية.
- لا يتم استيراد PDF؛ الاستيراد حالياً صور ونسخ `.waraqa` فقط.
- المصدر السابق لـAndroid محفوظ منفصلاً في `/workspace/waraqa`.

## الاختبارات

`npm run check` لفحص JavaScript، و`npm test` لفحص التقسيم وعدم ضياع بكسلات وهندسة الدمج والمنظور وبنية PDF ومنطق تعارض المزامنة.

`checks/browser.mjs` اختبار Chromium للواجهة المتجاوبة والاستيراد والدمج والتقسيم والقص والتحسين وتصدير PDF وإعادة التحميل والعمل بدون إنترنت. يعتمد على Playwright المثبّت كأداة تطوير، ويستخدم fixtures محلية فقط؛ بيانات الاختبار ليست بيانات المستخدم. نتيجة هذا الاختبار لم تُتحقق محلياً لأن صلاحية الشبكة لم تُمنح. GitHub Actions يشغله قبل النشر ويمنع النشر عند فشله.

## النشر عبر GitHub Pages

ارفع محتويات هذا المجلد إلى مستودع مخصص، دون `.openai/hosting.json` الذي يخص Sites. لا ترفع صورك أو بياناتك الشخصية. ملف GitHub Actions يشغّل فحوصات JavaScript والمنطق ثم اختبار Chromium للاستيراد والحفظ والدمج والتقسيم وPDF والعمل بدون إنترنت قبل النشر.

إذا فشلت خطوة configure-pages لعدم توفر صلاحية تفعيل Pages، افتح Settings → Pages → Source واختر GitHub Actions، ثم أعد تشغيل workflow. GitHub Pages للمستودعات الخاصة قد يتطلب خطة مدفوعة؛ المستودع العام مناسب للتجربة إذا أردت إتاحة الكود.

بعد النشر، افتح رابط Pages على Chrome في الهاتف، واستورد صورتين، وجرّب الدمج والتقسيم وتنزيل PDF. لتفعيل Drive أضف `https://YOUR_USERNAME.github.io` كـAuthorized JavaScript origin إلى إعداد OAuth (دون مسار المستودع).
