# قواعد السلوك / Code of conduct

نرحّب بالمساهمين بغض النظر عن اللغة أو الخبرة أو الهوية. ناقش الأفكار باحترام،
واشرح النقد بأمثلة، واحمِ خصوصية الآخرين. يمنع التحرّش والتهديد ونشر معلومات
شخصية أو مستندات خاصة، وكذلك الرسائل الدعائية المتكررة.

We welcome contributors of every background and experience level. Discuss ideas
respectfully, make criticism actionable, and protect personal information.
Harassment, threats, disclosure of private information and repeated spam are prohibited.

These rules apply to repository issues, PRs and other project-managed spaces.
Maintainers may edit/remove harmful content, close discussions or restrict access,
with proportionate action. Report ordinary moderation concerns to the maintainer
through an existing project thread without reposting sensitive content. A dedicated
private reporting contact has not yet been configured; do not publish private details.
