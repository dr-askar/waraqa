# Security / الأمان

Use the latest website assets and Android release. Older APKs may lack fixes to the
native bridge. Only the currently maintained release is actively reviewed; there is
no response-time guarantee or paid bug bounty.

Do not publish passwords, signing keys, document images or working exploits in a
public issue. If GitHub private vulnerability reporting is enabled, use
https://github.com/dr-askar/waraqa/security/advisories/new . Its availability depends
on repository settings. Otherwise ask for a private reporting channel in a public
issue containing only a general description; do not include exploit details.
The owner should configure a private security contact before store launch.

Include affected versions, reproduction steps using synthetic data, impact and
device/WebView versions in the private report. Report dependency issues upstream too.

المعالجة المحلية لا تلغي الحاجة إلى مراجعة الأمان. لا تنشر مفاتيح أو كلمات مرور
أو مستندات حقيقية في Issues. فتح رابط الإبلاغ الخاص لا يعني أنه مفعّل تلقائياً.
