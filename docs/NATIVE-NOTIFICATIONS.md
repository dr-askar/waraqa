# إشعارات أندرويد الأصلية — 6.1.0

WebView لا يوفر إشعارات المتصفح، ولذلك تستخدم نسخة أندرويد قناة أصلية منخفضة الأهمية وصامتة، مع أيقونة إشعار أحادية اللون. حسابي ← اختصارات الإشعارات يفتح إعدادات تشغيل/إيقاف وإعدادات النظام. النسخ السابقة تعرض رابط تحديث APK بدلاً من رسالة «المتصفح غير مدعوم».

إشعاران في مجموعة واحدة، بثلاثة أزرار لكل منهما: المسح / الهوية / الكتاب، والنص / التوقيع / الأدوات. جسم الإشعار يفتح المسح أو الأدوات. على بعض الأجهزة يجب توسيع المجموعة والإشعار لرؤية الأزرار؛ النظام يتحكم بالتوزيع. الإشعارات اختيارية وثابتة ما أمكن، ويمكن للنظام أو المستخدم إخفاؤها؛ ليست ضماناً لإشعار غير قابل للإزالة أو خدمة تعمل دائماً.

Android 13+ يطلب POST_NOTIFICATIONS عند الضغط على التشغيل فقط. عند الرفض أو حظر القناة توضح الواجهة الحالة وتوفر إعدادات أندرويد. إيقاف الاختصارات يلغي اللوحتين وملخص المجموعة ويحفظ الإعداد. التشغيل المختار يُستعاد عند فتح التطبيق لاحقاً إذا بقي الإذن متاحاً. لا خدمة خلفية ولا مستقبل إقلاع ولا إعادة إظهار مضمونة بعد إعادة تشغيل الهاتف دون فتح التطبيق.

الأزرار PendingIntent صريحة وغير قابلة للتعديل، مع قائمة أدوات مسموحة ومعرفات مستقلة. فتح بارد يستخدم رابط الأداة؛ فتح دافئ يمرر طلباً إلى واجهة التطبيق دون إعادة تحميل أو فقدان حالة الصفحة. التطبيق المقفل يحتفظ بالطلب حتى فتح القفل؛ العمليات الجارية لا تُقطع، وتغيير الأداة فوق مسودة يحتاج تنبيه المستخدم. لا أسماء مستندات أو محتويات حساسة في الإشعارات.

نسخة المتصفح تستمر باستعمال Web Notifications وService Worker؛ هذا ليس Push من خادم ولا إشعارات لمهام OCR بالخلفية. جميع المعالجة محلية كما كانت.

APK 6.1.0 له versionCode 60100، نفس package ونفس شهادة إصدار 6.0.0. تثبيته فوق السابق يحافظ على تخزين التطبيق؛ لا تحذف التطبيق لتحديثه. Chrome له تخزين منفصل. ملف التنزيل وSHA256SUMS وrelease.json محدثة. المفاتيح وكلمات المرور تبقى خارج المستودع.

التحقق: assembleRelease وassembleDebugAndroidTest وlintRelease؛ فحص توقيع الشهادة والإصدار والإذن في APK؛ test:android-bridge يختبر التشغيل والإيقاف والحظر والإعدادات ورسالة APK قديم وفتح أداة دافئ. اختبارات أندرويد تضيف إنشاء الإشعارين بستة أزرار، إرسال كل PendingIntent، ثبات صفحة WebView والإلغاء والفتح البارد وقائمة الأدوات المسموحة. محاكي أندرويد في CI مطلوب قبل الدمج، واختبار هاتف فعلي مطلوب لتقييم شكل إشعارات الشركة المصنعة.

الرجوع: revert عبر فرع مستقل مع اسم cache جديد أعلى من v30 عند نشر أصول مختلفة. يمكن إيقاف الاختصارات داخل التطبيق دون الرجوع. APK أقدم بversionCode أقل لا يثبت كتحديث فوق الجديد؛ إصدار رجوع يحتاج versionCode أعلى ونفس الشهادة. لا تعتمد على حذف التطبيق لأن ذلك يفقد تخزينه المحلي.

## الإصدار 6.1.1: صف أيقونات مدمج

تم استبدال اللوحتين وملخص المجموعة بإشعار واحد: مسح، هوية، كتاب، نص، توقيع، أدوات، كأيقونات متجاورة قابلة للضغط مباشرة. تخطيط RemoteViews ارتفاعه 48dp في الحالتين المطوية والموسعة، والأيقونات لها أوصاف مترجمة لقارئ الشاشة. ترويسة أندرويد تبقى تحت تحكم النظام. الإعداد السابق للتشغيل محفوظ، ويُلغى الإشعاران القديمان عند فتح التطبيق بعد التحديث.

APK 6.1.1 برقم 60101 ونفس الشهادة. نسخ 6.1.0 وما قبلها تعرض طلب تحديث لأن تحديث الموقع وحده لا يغيّر تصميم الإشعار الأصلي. اختبارات أندرويد تطبق RemoteViews وتتحقق من صف بستة عناصر وتضغط كل أيقونة فعلية، وتتحقق من وجود إشعار واحد وإلغاء المجموعة القديمة. يحتفظ CI بصورة لتخطيط الصف الأصلي. النقر والقفل والإذن تبقى كما في الإصدار السابق. shell v31؛ الرجوع يتطلب cache جديداً أعلى منه وAPK برقم أعلى إذا كان تثبيت إصدار رجوع مطلوباً.
