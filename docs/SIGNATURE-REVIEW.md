# مراجعة التوقيع

## الإصلاح

محرر التوقيع مستقل في signature-editor.js. سجل مسودة من أوامر الرسم بدلاً من صور كاملة لكل خطوة، مع تراجع وإعادة لآخر ثلاث عمليات. استعادة الرسم تستعيد أيضاً حالة الطمس، والتوقيع القابل لإعادة الاستخدام مشتق من رسم القلم الحالي بعد التراجع.

استيراد PNG يحافظ على الشفافية، مع خيار صريح لإزالة الخلفية البيضاء. حدود الصورة الشفافة تقص دون تغيير النسبة، والتحجيم والسحب يبقيان التوقيع داخل الصفحة حتى للصور الطويلة. الاستيراد يضيف لمسودة الصفحة؛ لا يستبدل التوقيع المحفوظ تلقائياً. زر حفظ التوقيع يحفظ الصورة المحددة أو رسم القلم الحالي لإعادة الاستخدام في أي مستند على الجهاز. اختيار صورة مستوردة ثم حفظ التوقيع يحفظ صورتها الأصلية الشفافة دون إطار التحديد أو خلفية الصفحة.

يمكن تحديد توقيع سابق باللمس من داخله، توسيطه أو حذفه. لمس الصفحة خارجه يتيح الرسم. إطار التحديد لا يدخل الصورة المحفوظة. إغلاق المحرر يلغي مسودة الصفحة، بينما حفظ رسم القلم في مكتبة التوقيع إجراء مستقل.

الحفظ يحافظ على الأصل وسجل الصورة السابق ويزيل OCR القديم. معاملة التخزين ترفض مستنداً تغير أو حذف أثناء التحرير، وتحافظ على المسودة مع رسالة لإعادة فتح أحدث نسخة. الإغلاق أثناء تجهيز الحفظ يمنع الالتزام إذا لم تبدأ المعاملة فعلياً.

## التحقق

- npm run check وnpm test.
- npm run test:signature: فحص واجهة الهاتف للرسم والتراجع والإعادة، عدم حفظ حبر تم التراجع عنه، الشفافية والحدود، إلغاء المسودة، استعادة علم الطمس، حفظ الأصل ورفض الكتابة فوق تعديل أحدث.
- npm run test:advanced: المسار السابق للتوقيع المحفوظ، وضعه، تراجع وإعادة الصورة، تشفير التوقيع واستعادته، بالإضافة إلى PDF والمحركات المحلية والعمل دون إنترنت.
- npm run test:browser: تجربة الهاتف والعمل دون إنترنت والتصدير.

## حدود

التوقيع مرئي وليس شهادة توقيع رقمية. إزالة الأبيض تعتمد عتبة لون محلية وقد تزيل حبرًا فاتحاً؛ الخيار غير مفعل افتراضياً. الصور المستوردة تخفض إلى ضلع أقصى 1600 بكسل. سجل المسودة ثلاث عمليات ويزول بالإغلاق؛ سجل الصفحة المحفوظة يبقى بحده الحالي، وليس تراجعاً شاملاً لكل المستند. الأصل والنسخ الاحتياطية قد يحتويان معلومات طُمست من الصورة النهائية.

## الرجوع عن الإصدار

Revert لطلب الدمج عبر فرع جديد. لا تغيير في مخطط قاعدة البيانات. عند نشر الكود المستعاد استخدم إصدار cache جديداً أعلى من v27 وحدّث meta وفحص التحديث الموافق؛ لا تعِد استخدام اسم cache لأصول مختلفة.

فحص إضافي: حفظ توقيع مستورد، إعادة تحميل التطبيق، استعادته من واجهة مستند آخر، حفظه في الصفحة الجديدة، والتأكد من استقلال صفحات المستند الأول وسلامة التوقيع بعد تشفير التخزين والقفل وإعادة الفتح.
